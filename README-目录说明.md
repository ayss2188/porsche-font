## ⚠️ 最重要的一条

**改这个项目之前，先想清楚主项目（`D:\ds\src`）要不要跟着改，或者反过来。**
两个项目共享 `common.sh` / `slots.sh` / `mount.sh` / `diag.sh` / `fontctl.sh` / `update.sh` 等引擘代码，
**改一边要在两个仓库都落地**（清单在 `module\common.sh` 顶部，9 条）。

**新规矩：一次同时做两个项目的更新，改完立刻对比。**
