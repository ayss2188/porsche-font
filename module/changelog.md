# 更新日志

## v4.5.9.3

### 一、高级设置：手动选择系统（给类原生 / 第三方包）

```
· 刷了第三方包、类原生的机器，自动识别可能不准（比如被认成别的os）
· 这类情况可以在 高级设置 → 系统识别 里手动指定目标系统：
  自动 / 澎湃OS / ColorOS / OriginOS / Flyme / 三星 One UI /
  红魔 / 荣耀 / 华为 / 原生
· 选完会自动重扫并重新生成槽位计划，重启生效
· 当然也可以生成一份完整报告，在反馈里写清楚机型和刷的是什么包，可以按报告做针对性适配
```

### 二、提示「QQ / 微信个别界面还是系统字体」

```
· 小米用户在系统设置里用 MiSans 时，这些界面会正常跟着模块换字体；
  但 MiSans 不支持粗细调节
· 想调粗细要切到「小米兰亭 Pro」，而它会让部分界面（QQ、微信的某些页面）
  改读「设置 → 字体样式」里那份主题字体 —— 优先级比 /system/fonts 高
· 所以只在设置里选「小米兰亭 Pro」时，这些界面不会跟着模块变
· 打开「也替换主题里选的字体」后，这份主题字体会被一起换掉，
  这些界面就会正常显示模块字体
· 小米用户推荐打开这个开关
```

### v4.4.9

> 对比基准：线上版本 **v4.4.8.2**。只写你能看到、能用到的变化。

#### 一、新增「高级设置」——本版重点

**这是什么**

一个**默认隐藏**的调试面板。以前遇到"字体没生效""某个 App 闪退""图标变方框"，只能翻报告；现在集中到一个带分区的面板里，每一项都写了它是干嘛的、怎么看结果。

**怎么进去**

```
1. 打开 WebUI，停在主界面
2. 滑到最下面，找到「当前版本」那一行
3. 连点 7 次（连续点，中途别停）
4. 弹出输入框 → 输入口令：cfs2026
5. 进入「高级（调试用）」
```

进去以后：

```
· 标题右边「锁定」：确认后主界面入口重新隐藏
  想再进：连点版本号 7 次 + 口令
· 右上角「✕」关闭；进入子页后变成「‹ ✕」
· 子页不显示「锁定」，避免误触
```

**分区只读保护**：面板先读你的系统。不是你系统的分区显示为只读，卡片上写「本机不是 X 系统」，点了没反应。

**分区与功能**

| 分区 | 项数 | 内容 |
|---|---|---|
| 界面自定义 | 15 | 背景图片（设置/清除）、背景预设三档、背景暗化、背景模糊、卡片不透明度、深浅色、强调色、圆角、标题字号、隐藏 Google 兼容卡片、隐藏反馈入口、简化模式、导出/导入界面设置、重新锁定、恢复默认界面 |

#### 二、安装流程修好了（本版最重要的一条）

```
v4.4.8.2：装完字体库是空的，安装时也不弹音量键选择
原因：安装脚本从来没有调用「导入内置配色」和「音量键选择」这两步

现在：
· 安装时提示「正在导入内置配色…」→「内置配色已导入：N 套」
· 然后弹出音量键选择（911 经典版 / 718 素装版 / GT3 赛道版）
· 选完直接应用，日志里显示「已应用：xxx」
· 重启后字体库里能看到这些内置配色
```

#### 三、界面外观：可换背景 + 毛玻璃

```
· 可以设一张自己的图当背景（原图导入，最大 24MB，不压缩）
· 所有浮层（字体列表、字属性、诊断报告、各种菜单）改成毛玻璃：
  背景模糊 + 面板半透明，压着图也能看清字
· 三档背景预设：预设一偏暗 / 预设二最亮最清 / 预设三最糊
  点一下自动把滑块调到对应值；手动拖过就显示"自定义"
· 三个滑块：背景暗化、背景模糊、卡片不透明度，拖动即时生效
· 有壁纸时按钮不再用强调色，避免抢眼
· 平板 / 横屏：模糊层按屏幕尺寸铺满，四周不再露一条清晰的边
```

#### 四、状态显示更准

```
· 「槽位总数 / 实际挂载 / 逐个核对」三项能取到真实数字（以前显示 "-"）
· 切换配色后，卡片"当前"立即更新，"待生效"标记正确
· 顶部数字在切换、拨开关后跟着刷新，不用手动刷新页面
```

#### 五、模块更新（检查 / 下载 / 安装）

```
· 修「检查更新一直卡在"检查中…"」：加超时与看门狗，
  最多十几秒一定给结果，失败也能再点
· 修「检查更新直接提示失败」：补上缺失的更新源定义
· 修「下载到的是主项目的包（只有 500 多 KB）」：
  子项目以前沿用了主项目的更新脚本，仓库名写死；
  现在按模块 id 自动选仓库与 update 文件，
  下载的是本项目的包（multi ≈ 65MB / 单配色 ≈ 22MB）
· 装完不会再变回"下载中"；重启后也不会残留红色「立即重启生效」
```

#### 六、卸载 / 重装更干净

```
· 卸载：物理删除背景图、清掉界面外观，重装后壁纸不再"复活"
· 重装：安装号变化时自动清掉上一套界面设置，回到默认外观
· 字体库仍按原规则：还有另一个字体模块装着时保留共享字体库
```

#### 七、这一版没有改的东西

```
· 默认行为：默认不替换任何系统字体
· 内置配色文件本身、判定规则：没动
· 机型识别与槽位扫描规则：与 v4.4.8.2 一致
```

#### 升级提示

```
1. 从 v4.4.8.2 覆盖安装即可，装完重启一次
2. 安装时注意选择配色（音量键切换、电源键确认）
3. 重启后打开 WebUI，字体库里应能看到内置配色
4. 想换背景：高级设置 → 界面自定义 → 设置背景图片
```
