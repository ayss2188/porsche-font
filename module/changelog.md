# 更新日志

## v4.5.5

> 大更新：三套配色全部换成新字体（补全韩文、符号、竖排与排版特性）。
> 从旧版本直接覆盖安装即可，装完重启。

### 一、字体更新（本版重点）

以最初版本 `主字体/none.ttf` 为基线，补全韩文、符号与排版特性，并修复原文件中的字形缺陷。

**新增：竖排支持**

```
· vhea / vmtx：全部 57,311 字形的垂直度量（字身 1000、竖排原点 880）
· vert / vrt2：27 组标点竖排替换（。→︒、「」→﹁﹂）
```

**新增：排版特性**

| 特性 | 内容 |
|---|---|
| kern | 778 组拉丁字对（AV / To / Yo / LV…） |
| palt / halt | 152 个中文标点的比例宽度（。 1000 → 325） |
| vpal / vhal | 同批标点的竖排比例宽度（。 竖排 1000 → 262） |
| BASE | ideo / romn 基线，hani / kana / hang / DFLT 脚本对齐 |

**优化：间距与度量**

```
· 33,014 个汉字在字身内居中（保留全字体统一光学偏移）
· 韩文音节按「墨迹中位宽 + 中文缝 120」定为 885 字身并居中，jamo 为 743
· 字间隙：纯中文 17–221（σ 62）→ 79–134（σ 18）
          纯韩文 σ 23、中韩混排 σ 24
```

**元数据**

```
· 补齐 name ID 7 / 8 / 11 / 19 / 25（商标、厂商、厂商网址、示例文本、变体 PS 前缀）
· 新增 meta 表（dlng / slng：zh-Hans, ko, en）
· 移除失效的 DSIG
```

### 二、升级安装会自动替换（OTA）

```
装新版本时会自动做四件事，不用手动删旧字体：
  ① 重新硬链接到新字体文件（inode 不同就换）
  ② 刷新名称与体积（界面显示 60.4 MB，不再是 57.4 MB）
  ③ 清理「新包里已经没有」的旧配色残留
  ④ 如果你当前用的就是内置配色 → 自动按新素材重新应用一次
装完重启，字形即生效。安装日志里能看到每一套的更新提示
```

### 三、槽位与扫描（与主项目 1.4.9.7 同步）

```
· Flyme 默认允许扫描本机字体（以前默认关，升级清掉清单后补不回来）
· 补全 Flyme 机型清单：DroidSans / DroidSans-Bold / DroidSansMono
· 升级时不再先删清单 —— 扫不到就沿用旧清单
· 点切换时清单为空 → 自动重扫一次再算
· 「重新数一遍」按清单内容判成功，不再误报扫描失败
```

### 四、包体积

```
单配色包：25.0 MB → 约 29 MB
多配色包：74.1 MB → 约 78 MB
（字体本身从 42.77 涨到 60.35 MB/份，属于预期）
```

### 升级提示

```
1. 从 v4.5.1 及以上直接覆盖安装
2. 装完重启一次，字形才会真正切换
3. 字体库里三套配色应显示 60.4 MB（旧的是 57.4 MB）
```
