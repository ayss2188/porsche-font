# 更新日志

## v4.4.9.18
> 对比基准：线上版本 **v4.4.9**。

### 一、三套内置配色换成新字体（本版重点）

```
· 字形数：36,790 → 50,239（+13,449）
· 字符映射：36,816 → 50,265
· 单个字体体积：42.77 MB → 57.41 MB
```

**补上了什么**

```
· 韩文：11,172 个音节全覆盖（含 Jamo、兼容字母、半角谚文，共 +422 字形）
· 符号：+1,835 个字形
    箭头 14 → 112        数学运算 44 → 256      杂项技术 3 → 178
    几何图形 16 → 96     杂项符号 5 → 136       装饰符号 21 → 166
    补充数学 / 箭头 / 标点 从 0 补齐（各 250 左右）
· 竖排：新增 vhea / vmtx（全部 50,239 字形的垂直度量）+ vert / vrt2 标点竖排
· 排版：kern 778 组拉丁字对、palt/halt 152 个中文标点比例宽度、vpal/vhal 竖排比例宽度
· 间距：33,014 个汉字在字身内居中；韩文音节按中文缝对齐
    纯中文字间隙 17–221（σ 62）→ 79–134（σ 18）
· 元数据：补齐 name ID 7/8/11/19/25，新增 meta 表（zh-Hans, ko, en），移除失效的 DSIG
```

### 二、升级安装会自动替换（OTA）

```
以前：升级完字体库里还是旧字形，得手动删掉重装
现在装新版本时会自动做四件事：
  ① 重新硬链接到新字体文件（inode 不同就换）
  ② 刷新名称与体积（界面显示 57.4 MB，不再是 42.8 MB）
  ③ 清理「新包里已经没有」的旧配色残留
  ④ 如果你当前用的就是内置配色 → 自动按新素材重新应用一次
装完重启，字形即生效。安装日志里能看到每一套的更新提示
```

### 附：怎么进「高级设置」（4.4.9 新增，没看过的可以记一下）

```
1. 打开 WebUI，滑到最下面
2. 找到「当前版本」那一行，连点 7 次
3. 输入口令：cfs2026
4. 进去后可以设背景图、开毛玻璃、调透明度，也有各机型专区的排查开关
   · 锁上后想再进：还是连点 7 次 + 口令
   · 不是你系统的分区是只读的，点了没反应，防止误触
```
