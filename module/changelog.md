# v4.6.0 更新日志

适用范围：v4.5.9.4 → v4.6.0

## 首次安装说明

- 4.6.0 是目录迁移版本，必须安装**完整包**。
- 迁移完成后，后续更新改用 lite 包（不带内置字体）。
- lite 包最低要求：模块 versionCode ≥ 460000、目录布局 ≥ 2、已有内置字体。

## 字体与 TTC

- TTC 计划缓存纳入 `ttc.list`，TTC 清单变化后不再复用旧的无 TTC 计划。
- TTC 缓存清理按字体整组处理，Sans / Serif 不再出现只删一个的情况。
- “全部保留”不再执行文件数 / 2GB 容量清理，不再把一套字体拆成单个文件。
- 字体更新或回滚后清空 TTC、锁屏时钟、计划、字体派生缓存，避免旧字形残留。
- 保留当前字体 / 待生效字体的 TTC 缓存，不再被开机清理误删。

## 锁屏时钟

- 锁屏时钟配套继续由 porsche 插件生成，模块负责挂载和生命周期。
- 增加时钟配套体检：包围盒、度量、advance 检查。
- 切换字体时先生成待生效时钟，重启确认后再按预设清理旧时钟。
- 开机 service 增加时钟 / TTC 缓存清理。
- 锁屏时钟状态、详情和缓存列表统一显示。

## 字体工具箱

- 工具箱的界面、分类、工具名称和说明改由插件 `ui/ui.json`、`ui/tools.json`、`ui/toolbox.css` 提供。
- 模块通过 `engine.sh run ui --json` 加载插件 UI，插件更新不再必须同步更新模块。
- 字体选择改成“先点工具，再选择字体”，不再常驻英文文件名下拉框。
- 保留插件本地导入和 Root 管理器安装拦截。
- 工具箱底部显示插件版本、作者、构建号。

## 字体包独立更新

- 新增签名字体包 v1.0，字体包与模块分开更新。
- 字体包使用 porsche 插件同一把 Ed25519 密钥签名；模块内置公钥校验。
- 字体包包含 `MANIFEST.sha256`、`SIGNATURE`，用户自行加入字体无法通过校验。
- 字体包必须匹配模块变体（multi / 718 / 911 / gt3）和最低模块版本。
- 字体包支持从 GitHub 安装、从本地 zip 导入，以及用旧版字体包回滚。
- 字体包在 Root 管理器刷入时会明确提示“这是字体包，不是模块”并中止。

## 模块 lite 更新

- 完整包首次安装，lite 包后续更新；两者使用同一个模块 ID 和更新地址。
- lite 包不包含 `builtin/*.ttf`，安装时保留现有内置字体。
- lite 包拒绝首次安装和 4.5.x 直接升级，避免跳过目录迁移。
- 完整包和 lite 包的更新检测、更新日志统一走阿里云，更新包支持阿里云 / GitHub 双线路。

## 缓存与状态

- 缓存列表顺序统一为：待生效 → 当前在用 → 未使用。
- 切换字体时遮罩保持到刷新完成，卡片、遮罩、状态卡三处同步收口。
- 字体包版本默认 v1.0，完整 4.6.0 安装后写入 `font.pack.json`。
- lite 更新不覆盖字体包版本，避免把用户已升级的字体包改回 1.0。

## 诊断报告

- 诊断增加 TTC 结构校验，使用模块内置 `ttc_verify`。
- 计划统计支持 `cache/plan/*.map` 和 `slots.map` 回退，不再显示“没有留存计划”。
- PID 1 视角说明改为仅代表该命名空间，最终以实际生效校验为准。
- 报告区域禁止横向滚动，长路径和长行自动换行。

## 兼容与数据

- 保留用户导入字体、设置、壁纸、锁屏时钟和备份。
- 4.5.x 升级会执行目录迁移，迁移失败则中止安装，不破坏旧数据。
- 卸载仍会删除字体库，卸载后需要重启再安装。

## 已知说明

- 内置字体包 v1.0 的覆盖率字段仍为“未记录”，诊断报告会显示这一项，但不影响挂载和切换。
- GitHub 字体包下载依赖网络；连不上时请使用本地导入签名包。
