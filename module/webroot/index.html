替换范围
日文、韩文、繁体、时钟、代码、斜体 —— 全部都会换成你的字体，不用设置。
如果某个字没变、或者显示成方块（□），那是你的字体里没有那个字；诊断报告里会列出是哪些。
也替换主题里选的字体
有些机型会把「设置 → 字体样式」或主题商店里选的那份字体单独存一份，它比系统字体优先，不换它就不生效。
开：那份也换成你的字体，设置里的选择会失效。
关：只换系统字体（小米想用「字体粗细」调粗细就保持关）。
保留锁屏时钟字体
小米/红米/POCO 的锁屏时钟有自己专用的一份字体，默认会一起换成你的字体。
开：那几份保留原样，你还能在系统里换锁屏时钟样式。
关：连锁屏时钟也换成你的字体。
（其他品牌没有这种专用字体，开关无影响）
自带挂载
开：模块自己把字体挂上去（推荐，不用装元模块）。
关：交给 Root 管理器 / 元模块来挂。
改完会自动重新生成，重启生效。

让字体生效
换了字体后有两种做法，内容一样，只是快慢和稳当程度不同：
免重启不用重启，点一下就生效（屏幕黑一下、约 30~60 秒）。 临时 root 用户必须走这条 —— 他们重启后 root 会掉、开机脚本也不会跑。
最稳重启手机 —— 模块在开机时自己挂载，一次到位。 清缓存、恢复出厂那种，都靠这条路。
点它会让屏幕黑一下、所有 App 重新加载，约 30~60 秒恢复 —— 这期间别乱点。
它不改开机行为（模块还是照常自己挂载），只是把这次应用提前到现在。
重启一次，模块在开机时自己挂载 —— 以后每次开机都照常生效
开机异常时：进入安全模式或在管理器里禁用本模块即可恢复
