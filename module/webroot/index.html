替换范围
日文、韩文、繁体、时钟、代码、斜体 —— 全部都会换成你的字体，不用设置。
如果某个字没变、或者显示成方块（□），那是你的字体里没有那个字；诊断报告里会列出是哪些。
也替换主题里选的字体
有些机型会把「设置 → 字体样式」或主题商店里选的那份字体单独存一份，它比系统字体优先，不换它就不生效。
开：那份也换成你的字体，设置里的选择会失效。
关：只换系统字体（小米想用「字体粗细」调粗细就保持关）。
保留锁屏时钟字体
小米/红米/POCO 的锁屏时钟有自己专用的一份字体，默认会一起换成你的字体。
开：那几份保留原样，你还能在系统里换锁屏时钟样式。
关：连锁屏时钟也换成你的字体。
（其他品牌没有这种专用字体，开关无影响）
自带挂载
开：模块自己把字体挂上去（推荐，不用装元模块）。
关：交给 Root 管理器 / 元模块来挂。
改完会自动重新生成，重启生效。
