内置配色（点击卡片切换）
这些配色是刷机时随模块装进来的，重启后生效。 不支持导入外部字体——这是内置配色版，只在本模块自带的几套之间切换。
替换范围（高级）
也替换「设置里选的字体」（主题 / 字体样式）
MIUI / HyperOS（/data/system/theme/fonts）、三星（/data/overlays/font）、vivo（/data/vfonts）都会把你「设置 → 字体样式」里选的字体放在单独目录，那里的文件优先级高于系统字体目录。不设默认值 = 按机型自动判：
· 小米这类机型会先看主题目录里那份字体是不是可变字体：是 → 不碰它（你选「小米兰亭 Pro」正是为了用它的字重轴调「字体粗细」，模块会放过它、粗细照常能调）；
· 开：这些目录也换成配色字体，好处是不用再去设置里切回「默认」；代价是设置里选的那个字体失效。
例外：vivo 的 /system/fonts/VivoFont.ttf 是指向该目录的符号链接，它本身仍按普通槽位替换。
模块自带挂载（推荐）
开：模块自己把字体挂上去，不需要装元模块，能覆盖 my_product、mi_ext 等厂商分区。
关：交给 Root 管理器 / 元模块挂载（传统方式）。
修改后会按当前选择自动重新生成，重启生效。
替换范围说明
日文、韩文、繁体、时钟、代码、斜体 —— 全部都会换成配色字体，不用设置。
如果某个字没变、或者显示成方块（□），那是配色字体里没有那个字；诊断报告里会列出是哪些。
