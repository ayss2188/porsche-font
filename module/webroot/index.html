在内置浏览器里勾选一个或多个 .ttf/.otf，一次导入，直接复制，速度很快。TTC 合集请先用刷机包 tools 里的 optimize_font.py 拆出单个字体（电脑或手机 Termux 均可）。
所选字体会套用到所有字重槽位：静态字体各字重外观相同，可变字体(VF)可保留粗细变化。字体需含中文字形，否则中文会回退到系统字体。
替换范围（高级）
保留繁体 / 日文 / 韩文字体槽
开着（推荐）：繁体、日文、韩文继续用系统字体，显示正常。想让繁体也用你的字体，就关掉它 —— 但你的字体缺哪个字，哪个字就会变方块（简体字库常缺「靉」「鶚」这类冷门繁体）。
保留衬线 / 等宽 / 时钟 / 斜体等特殊槽
开着（推荐）：终端等宽字、锁屏时钟、衬线、斜体继续用系统字体，避免全文都变成一个样。想让这些也用你的字体，就关掉它。
模块自带挂载（推荐）
不需要元模块，能覆盖 my_product、mi_ext 等厂商分区。关闭后交给 Root 管理器 / 元模块挂载（传统方式）。
修改后会按当前选择自动重新生成，重启生效。
