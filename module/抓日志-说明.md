抓日志 / 打开 WebUI（不用进界面也能用）
==========================================

这个目录里的几个 .sh 文件，用 MT 管理器点「执行」→ 选「以 root 身份执行」即可。
它们是给「Magisk 没有操作按钮」「WebUI 正好在闪退」这类情况准备的备用入口。

  抓日志-开始.sh      开始抓日志（后台记录，正常用手机即可）
  抓日志-停止导出.sh  停止抓取 → 生成 Download/崩溃日志_时间.txt
  抓日志-状态.sh      看正在不在抓、抓了多久、文件多大
  打开WebUI.sh        尝试打开本模块的 WebUI（Magisk 需先装 KsuWebUI / WebUI X）

典型用法（App 闪退）：

  1) 执行「抓日志-开始.sh」
  2) 去复现：把「卸载模块」关掉，打开会闪退的 App，让它崩一次
  3) 执行「抓日志-停止导出.sh」
  4) 把 Download/崩溃日志_时间.txt 发给作者
     （如果可以进 WebUI：界面上「⑤ 抓崩溃日志」里有一样的按钮，还能一键上传）

注意：
  · 这些文件需要 root 才能执行（MT 里要选「以 root 身份执行」）
  · 抓日志期间不影响正常使用，文件滚动保存，最多占几十 MB
  · 忘了停止也没关系：下次开机会自动接着抓（不会丢）
