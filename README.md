**保时捷字体（内置配色版）**

给手机换上保时捷的那套字形和那点红。三套配色随模块打包，刷入时选一套，之后在 WebUI 里随时切。

三、刷入步骤

1. **下载**：从上面表格里选一个 zip
2. **刷入**：管理器里选「从本地安装」，选中 zip
3. **选配色**：音量 **[下]** 切换、**[上]** 确认（单配色包自动选中，不弹菜单）
4. **重启**：刷入完成后重启手机
5. **切一次字体**（**小米 / 澎湃必做**，其他系统一般不用）
   设置 ➔ 显示 ➔ 字体大小和样式 ➔ 切换到**【小米兰亭Pro】**

> ⚠️ 第 5 步别跳过。系统默认字体不支持调节粗细，切到小米兰亭Pro 才会触发全量重新加载 ——
> 这一步 v3 一样要做，不是模块没生效。

**怎么打开 WebUI**

- **KernelSU / APatch**：管理器模块列表里点 WebUI 入口
- **Magisk**：点模块卡片上的「**操作**」按钮

五、主要功能（一句话版）

- **三套保时捷配色**随包内置，WebUI 里热切换
- **多系统自动适配**，刷入自动认系统
- **中文也能换**（三星 / 魅族 / vivo 等机型）：本机中文如果来自 `.ttc` 合集，会把配色包成
  同样 face 数的合集顶上去，**只换中文那几号**，日文 / 韩文保留系统字形；这类机型自动打开，界面里可关
- **不动你「设置里选的字体」**：MIUI / 三星 / vivo 的主题字体目录默认不碰，
  所以「小米兰亭 Pro」和「字体粗细」都还在（想在界面里打开也支持）
- **谷歌字体兼容**开关：解决 Chrome / Gmail 英文数字被 GMS 换回默认的问题
- **在线更新**：管理器提示新版本，下载后自动校验 sha256 与包内 ID，不符就不装
- **开机保护**：万一选的配色导致没能开机，下次开机自动恢复；连续两次失败会自动停用模块，保证能进系统
- **诊断报告**：一键生成，把「为什么没生效」直接说清楚；「只有桌面生效、App 里没变」也能直接定位
- **可逆**：只读挂载、不改系统分区，禁用或卸载即恢复

具体实现方式见 [更新日志](CHANGELOG.md)。

六、升级说明

**从 v3.0 上来**：直接覆盖安装即可，**不用卸载**。你选的配色和设置都会保留。

**从 v2.0 上来**：同样直接覆盖安装，**不用卸载**。你原来选的配色会被自动认出来并保留。

**从 v1.x 上来**：**必须先卸载旧模块再刷**（id 不同，不卸载会同时装两个、互相抢字体）。

```
卸载旧模块重新安装
卸载旧模块重新安装
卸载旧模块重新安装
```

v3.9 的变化（对方便理解升级后表现有帮助）：

- **诊断报告快多了**：以前慢的机型要等接近半小时，现在几分钟。报告内容一行没少
- **点报告后可以选「全速生成」或「慢慢生成」**：两种模式**内容完全一样**，只是快慢和"占不占手机"
- **报告开头会声明"这次有没有哪一节没测到"** —— 以前某一节什么都没测到时，报告会显示成"没问题"，
  现在会明写出来（宁可难看，不许静默）
- **报告多了两节**：`【4】语言 → 字体文件`（哪种语言对应哪个文件、本次会不会换）、
  `【5】没被替换的字体`（分「★要修」和「正常排除」）

v3.6 的变化（对方便理解升级后表现有帮助）：

- **修好了"有些手机满屏方块"**：一加 / OPPO 这类机型以前会出现桌面、微信、设置全是方框
  （而时钟数字正常）。原因是配色字体对外"自称的名字"是坏的，现在改成了规范写法 ——
  **字形和配色一个字都没动**，只改了名字
- **替换范围不再有开关**：日文 / 韩文 / 繁体 / 时钟 / 代码 / 斜体**一律都换**（以前要自己选）。
  唯一的例外：你的字体完全没有中文字形时，一个槽位都不换（防止界面变方块、连换回来的按钮都点不到）
- **没适配过的机型也能用了**：改成读你自己手机里的字体配置来定位，不再只认少数几个品牌
- **诊断报告开头新增一节**：直接列出"哪种语言 → 哪个文件 → 换没换 → 为什么"

v3.5 的变化（对方便理解升级后表现有帮助）：

- **不再替换「设置里选的字体」**：如果你在 设置 ➔ 字体样式 里选过字体（比如小米兰亭 Pro），
  升级后它不会再被模块顶掉 —— 这是刻意的（v3.0 顶掉它会让「字体粗细」调不动）
- **三星 / 魅族 / vivo 用户**：升级重启后中文会跟着配色变（以前是"英文变了、中文没变"）。
  每个 `.ttc` 会在 `/data` 里多占「原合集 + 配色字体」那么大的空间（约 40~90MB），空间不足会自动跳过
- **万一中文变方块**：WebUI ➔「替换范围（高级）」➔ 关掉「替换 .ttc 合集」➔ 重启，即可完全恢复

其他：
- v3 是**内置配色版**，不再支持导入外部字体
- v3 **不再需要元模块**，原来装的 Hybrid Mount 之类可以留着，也可以停用
- v2.0 的 Magisk 版曾自动装过一个 KsuWebUI 应用，升级后不会卸载它，留着不影响使用

七、刷完没变化？

1. 打开 **WebUI**，看「实际挂载」和「实际生效（逐个核对）」的数字
2. 小米 / 澎湃用户：确认已按第三节第 5 步切到【小米兰亭Pro】
3. 还不行：WebUI 里点「查看诊断报告」→「保存到 Download」，
   把报告 + 机型 + 系统版本发到评论区或 [Issues](https://github.com/ayss2188/porsche-font/issues)

八、已知局限

- **谷歌商店（Play Store）**：新版把 Google Sans 打包进了 APK，属"应用内置字体"，任何系统级模块都换不掉 —— Chrome / Gmail 生效、商店不变属正常现象
- **QQ、微信**个别页面走独立渲染，不会随系统改变；**网页 / 小程序**里的字（WebView 渲染进程）也不受系统字体模块影响
- **`.ttc` 合集替换的"只换中文"混合方案还没有真机确认**（已确认的是"换合集后中文跟着变"）。
  v3.6 起这一项也**不再有开关**（按机型自动判断、自动开），所以"关掉它"这条路没有了；
  万一中文出现方块，请选「无字体（系统默认）」再重启。
- **⚠️ 自带配色没有韩文字形**（实测 0/56 个常用韩文字）。
  v3.5 曾写"不会出现日文韩文方块"—— **这句对韩文不成立**，这里更正。
  v3.6 起替换范围一律全替换、不再有「保留韩文」开关，所以**如果你要看韩文，
  韩文槽位被换掉后会是方块**；这种情况请先用卡片里的「无字体（系统默认）」恢复对比确认。
  （繁体、日文不受影响：字体里这两类的字形是齐的。）
- **「也替换设置里选的字体」**：现在**按机型自动判断**（不设默认值就按机型走）。
  小米这类机型会先看主题目录里那份字体是不是**可变字体**：是 → 不碰它
  （你选「小米兰亭 Pro」正是为了用它的字重轴调「字体粗细」，模块会放过它、粗细照常能调）；
  不是 → 一起换。界面里仍可手动指定开/关
- 个别机型把字体放在更深的自定义分区时，主界面中英文字体仍会生效，100% 全覆盖需视具体 ROM 而定
