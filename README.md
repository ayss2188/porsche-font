**保时捷字体（内置配色版）**

给手机换上保时捷的那套字形和那点红。三套配色随模块打包，刷入时选一套，之后在 WebUI 里随时切。

三、刷入步骤

1. **下载**：从上面表格里选一个 zip
2. **刷入**：管理器里选「从本地安装」，选中 zip
3. **选配色**：音量 **[下]** 切换、**[上]** 确认（单配色包自动选中，不弹菜单）
4. **重启**：刷入完成后重启手机
5. **切一次字体**（**小米 / 澎湃必做**，其他系统一般不用）
   设置 ➔ 显示 ➔ 字体大小和样式 ➔ 切换到**【小米兰亭Pro】**

> ⚠️ 第 5 步别跳过。系统默认字体不支持调节粗细，切到小米兰亭Pro 才会触发全量重新加载 ——
> 这一步 v3 一样要做，不是模块没生效。

**怎么打开 WebUI**

- **KernelSU / APatch**：管理器模块列表里点 WebUI 入口
- **Magisk**：点模块卡片上的「**操作**」按钮

====================================

五、主要功能（一句话版）

- **三套保时捷配色**随包内置，WebUI 里热切换
- **多系统自动适配**，刷入自动认系统
- **谷歌字体兼容**开关：解决 Chrome / Gmail 英文数字被 GMS 换回默认的问题
- **在线更新**：管理器提示新版本，下载后自动校验 sha256 与包内 ID，不符就不装
- **开机保护**：万一选的配色导致没能开机，下次开机自动恢复，不会一直卡
- **诊断报告**：一键生成，把「为什么没生效」直接说清楚
- **可逆**：只读挂载、不改系统分区，禁用或卸载即恢复

具体实现方式见 [更新日志](CHANGELOG.md)。

====================================

六、升级说明

**从 v2.0 上来**：直接覆盖安装即可，**不用卸载**。你原来选的配色会被自动认出来并保留。

**从 v1.x 上来**：**必须先卸载旧模块再刷**（id 不同，不卸载会同时装两个、互相抢字体）。

```
卸载旧模块重新安装
卸载旧模块重新安装
卸载旧模块重新安装
```

其他：
- v3 是**内置配色版**，不再支持导入外部字体
- v3 **不再需要元模块**，原来装的 Hybrid Mount 之类可以留着，也可以停用
- v2.0 的 Magisk 版曾自动装过一个 KsuWebUI 应用，升级后不会卸载它，留着不影响使用

====================================

七、刷完没变化？

1. 打开 **WebUI**，看「实际挂载」和「实际生效（逐个核对）」的数字
2. 小米 / 澎湃用户：确认已按第三节第 5 步切到【小米兰亭Pro】
3. 还不行：WebUI 里点「查看诊断报告」→「保存到 Download」，
   把报告 + 机型 + 系统版本发到评论区或 [Issues](https://github.com/ayss2188/porsche-font/issues)

====================================

八、已知局限

- **谷歌商店（Play Store）**：新版把 Google Sans 打包进了 APK，属"应用内置字体"，任何系统级模块都换不掉 —— Chrome / Gmail 生效、商店不变属正常现象
- **QQ、微信**个别页面走独立渲染，不会随系统改变
- **`.ttc` 合集字体**（如 `NotoSansCJK-Regular.ttc`）不会被替换
- 个别机型把字体放在更深的自定义分区时，主界面中英文字体仍会生效，100% 全覆盖需视具体 ROM 而定

====================================

九、卸载

管理器里卸载模块即可：会一并清掉字体库，**系统字体自动恢复**。
