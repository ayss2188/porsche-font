====================================

一、详细介绍

1. 核心技术：真实可变字体（Variable Font 150~700）

市面上很多移植字体模块为了省事，直接拿粗体和细体"复制粘贴"凑字重，导致系统调节字体粗细时出现拉伸变形、笔画发糊或粗细断层。本模块采用真正的 Variable Font（可变字体技术），支持 wght 轴 150 ~ 700 的连续粗细插值。不论你在系统设置里把字体调细还是调粗，字体都能实现无级平滑过渡，笔画节点精准，绝不失真。

2. 深度适配：多系统无死角覆盖 + 刷机脚本黑科技瘦身

- 为什么需要"动态目标槽"？ 不同系统的字体槽数量差异很大：HyperOS 有 64 个，ColorOS 更是上百个，OriginOS / Flyme / 原生也各不相同。本模块在刷入时自动识别当前系统，按该系统的真实字体槽清单批量覆盖，不多不少、无死角，避免"字体混搭/未替换"的突兀感。
- 刷机脚本动态本地生成（下载体积直降 98%+）
  - 传统方案痛点：保时捷可变字体单文件体积达 40MB+，如果为每个系统、每个字体槽都打包一份完整文件，包体将轻松突破数 GB（仅 HyperOS 就要 64 份），极易导致下载失败或存储空间不足。
  - 原理解析：模块 Zip 内仅保留核心字体文件 + 各系统的目标槽清单（纯文本、几乎零体积）。刷入瞬间，由安装脚本自动识别系统，在手机本地生成并重命名为该系统所需的全部目标文件。
  - 最终效果：无论适配多少个系统、多少个字体槽，下载体积始终只有 40MB 左右（三合一带三套配色约 63MB），挂载效果又与完整包 100% 完全一致。

3. 创新玩法：保时捷特色配色（刷入 / 后续随时热切换）

- 🤍 素装版：纯粹替换字体字形，标点与符号颜色完全跟随系统原汁原味。
- ❤️ 一点红（911经典版）：仅将时间显示的冒号（例如 12∶00）染色为保时捷官方经典的"卫兵红"（Guards Red #D5001C）。
- 🔥 烈焰（GT3赛道版）：在一点红基础上，针对 @、!、？、！、…、★ 等强调型标点符号同步染色，视觉冲击力极强。
- 预览字体参考（图1）

4. 多系统自动适配

本模块从「仅适配澎湃OS」升级为「多系统自动适配」，刷入时会自动识别当前系统并选用对应的字体槽清单：

- 小米系：澎湃OS / HyperOS / MIUI（小米 / 红米 / POCO）
- OPPO 系：ColorOS（OPPO / 一加 / realme）
- vivo 系：OriginOS（vivo / iQOO）
- 魅族：Flyme
- 原生 / 类原生 / 谷歌 Pixel / GSI：兜底通用适配
- 三星 One UI、荣耀 MagicOS、华为 EMUI / 鸿蒙（AOSP 兼容版）、Nothing OS：通用适配

实现要点：

- 针对不同 ROM 内置了各自验证过的字体槽清单（MiSans、SysFont/SysSans、OplusSans、VivoSans、FlymeSans、Roboto/GoogleSans 等），按识别结果自动选用；
- 对 OriginOS / Flyme 等字体名非标准的系统，安装时会额外扫描真实字体目录、按分区补全，确保覆盖到位；
- 刷入后 `module.prop` 状态栏会直接显示「识别到的系统」和「当前生效的配色」，一眼确认适配结果。

> 说明：本模块覆盖系统字体链路（/system、/system_ext、/product 等分区）。个别机型把部分字体放在更深的自定义分区时，主界面中英文字体仍会生效，但 100% 全覆盖需视具体 ROM 而定。

5. 自带挂载：不用再装元模块（v3 新增）

v2.0 时代，KSU / APatch 用户必须先刷一个元模块（如 Hybrid Mount）并重启，否则字体挂不上。v3 起模块**自己就能挂载**，元模块不再是必需品：

- 原理：把字体文件 **bind mount**（绑定挂载）到每一个真实存在的字体槽路径上。系统去读 `/system/fonts/xxx.ttf` 时，读到的其实是模块字体库里的文件，**物理分区一个字节都没改**；
- 只读：挂载后立即 remount 成只读，运行期不可写；
- 零重复占用：所有槽位都指向同一个文件，替换一百个槽位也只占一份字体的空间；
- 重启即还原：挂载只存在于内存，重启自动消失，不存在残留；
- 挂载时机：**所有管理器都在 `post-fs-data` 阶段挂载**（这是各管理器唯一保证会执行的阶段）。支持 `post-mount` 的管理器还会在那个阶段再做一次**修补**：如果其他模块的目录级挂载把我们的文件盖住了，会靠 inode 比对发现并补回来（幂等，不会叠挂载）；
- 覆盖范围包含 my_product、mi_ext、oplus_product、vivo、prism 等厂商分区 —— 这些分区里的字体槽，很多元模块并不支持；
- 个别环境自带挂载不工作时，可以在 WebUI 里一键切回「交给管理器挂载」（传统方式）。

6. 谷歌字体兼容

谷歌商店、Chrome、Gmail 等 Google 应用有时会通过 GMS 的 FontsProvider 下载官方 Google Sans，导致英文数字又变回默认。本模块内置「谷歌字体兼容」开关（WebUI 内操作）：

- 原理：仅停用 GMS 的 `FontsProvider` 组件（可逆、不卸载、不清数据、不动账户）；
- 效果：Chrome、Gmail 等 Google 应用的英文数字回退到系统字体（即本模块字体），开启后立即生效，无需重启；
- 可逆：随时可一键「关闭兼容」恢复原状态；只恢复本模块自己停用过的组件，不会越权改动你手动停用的东西；
- 卸载模块时自动恢复。

💡 已知局限：谷歌商店（Play Store）新版把 Google Sans 直接打包进了 APK，属于"应用内置字体"，任何系统级字体模块都无法替换 —— Chrome / Gmail 生效、商店不变属正常现象。

7. GitHub 在线更新（自动校验，装不坏）

- WebUI 内「检查更新 / 更新日志 / 下载并安装」，不用再翻帖子找新版；管理器的模块列表里也会提示「有更新」；
- **先校验再安装**：校验 sha256（发布时由 GitHub Actions 自动写入）+ 校验包内模块 ID，任何一项不符都会**取消安装**；
- **更新通道自动匹配**：你装的是哪个包，更新时就给你哪个包 —— 单配色用户不会被更新成三合一，反之亦然，不需要你手动挑；
- 更新 / 覆盖安装**不会清空**你的配色选择和设置，重启后自动恢复。

8. 界面与状态：能看清"到底生效了没有"

不少模块的通病是"界面显示切了、实际没生效"。本模块的状态是按**实测**给的：

- 「当前实际生效」：此时此刻系统正在用的配色；
- 「待生效（下次重启后）」：你刚点选、已生成好的新配色；
- 「已替换槽位 / 实际挂载」：本次替换了多少个槽位、开机时成功挂载了多少个（会写清成功 / 失败 / 已就位 / 跳过各多少）。槽位在上一次开机就已经挂好、本次开机没有新的挂载动作时，这里显示「本次开机未改动（已就位 N）」—— **字体是好的**，不要误以为没生效；
- 「实际生效（逐个核对）」：按文件 inode 逐个核对到底哪几个槽位真的换上了 —— 这才是"有没有生效"的答案；
- 「识别系统」：当前识别到的 ROM。

生效方式：点页面底部「立即重启生效」，或自行重启手机。

9. 开机保护

选完配色的第一次重启是最危险的时刻。模块的做法：

- 选配色后写一个 `.booting` 哨兵；
- 下次开机时若哨兵还在（说明上次没走到系统启动完成），会自动撤销全部字体文件、把选择恢复成「无字体」，并在界面提示「上次开机失败，已自动恢复」；
- 只有真的选过配色才会看守，平时开机的开销为零。

需要如实说明：这是尽力而为的保护 —— 极端情况（卡在系统启动完成之前）可能还需要你再重启一次才能恢复。

💡 已知局限

- QQ 内部个别页面（如安全中心通知）字体不会随系统改变，这是因为其走独立的渲染逻辑，不影响系统其他所有功能正常使用；
- 谷歌商店（Play Store）因内置字体，无法被系统级模块替换（详见上文「谷歌字体兼容」）；
- 游戏、阅读器、网页里指定的字体、图片里的文字，不经过系统字体，不受影响。

二、版本选择指南

v3 起**不再区分管理器版本**，一共 4 个包，按想要的配色挑一个即可：

1. 三合一版（`porsche-font-multi-v3.0.zip`）

- 适用：想随时切换配色的用户。
- 特点：内置素装 / 一点红 / 烈焰三套配色，WebUI 里点卡片随时切换，重启生效。
- 体积：约 63MB。

2. 单配色版（`porsche-font-718 / 911 / gt3-v3.0.zip`，共 3 个包）

- 适用：强迫症、追求最小体积、明确只喜欢某一套配色的用户。
- 特点：只带一套配色，刷入即用；同样具备「多系统自动适配 + 谷歌兼容 + 自带挂载 + 在线更新」。
- 体积：约 21MB。
- 注意：单配色包**没有**切配色功能；想换配色请刷另一个包（模块会自动把前一个标记为重启后卸载，不会打架。）

> 四个包**只装一个**。同时装两个会互相抢系统字体。
> Magisk / KernelSU / APatch **同一个包都能装**，不用再按管理器挑。

三、刷前准备与避坑指南（必看！）

- Root 权限环境：支持 KernelSU / APatch / Magisk。
- **先停用其他字体模块**：多个字体模块会互相覆盖，包括你之前装的旧字体模块。
- KSU / APatch 用户：关闭管理器的【默认卸载模块】选项，避免被隔离的应用看到的是系统默认字体。
- **v3 不再需要元模块**（Hybrid Mount 之类）。你原来装的元模块可以留着（不影响），也可以停用。
- Magisk 没有原生 WebUI 入口，需要先安装 KsuWebUI（包名 `io.github.a13e300.ksuwebui`）或 WebUI X。

四、关键设置：解决"部分生效 / 没完全变"问题（刷完必做）

如果刷入重启后发现字体"有的地方变了、有的地方没变"（例如设置界面变了但桌面没变）：

- 原因：因为本模块替换的部分字体文件中包含了 MiSans 的底层逻辑，如果系统当前使用的字体依然是默认的 MiSans，会导致部分系统资源被原厂覆盖。
- 解决方法：
  1. 打开手机 设置 ➔ 系统个性化；
  2. 点击 字体，进入"字体样式和大小"页面；
  3. 将系统字体手动切换为【小米兰亭Pro】；
  4. 切换后即会触发系统全量重新加载，字体即可实现全局完美替换！
  5. 参考（图3）

> 说明：此「切换小米兰亭Pro」步骤**仅小米 / 澎湃系统需要**。ColorOS、OriginOS、Flyme、原生系统一般无需此步，刷入重启即可。
> 另外，如果刷完打开 WebUI 看到「实际生效（逐个核对）」的数字明显小于「已替换槽位」，也请先做这一步。

五、详细刷入与配置教程

1. 通用刷入步骤（4 个包都一样）

- Step 1（选择文件）：打开你的 Root 管理器（Magisk / KernelSU / APatch），进入【模块】页面，点击「从存储安装 / 从本地安装」，选中下载好的 Zip。
- Step 2（音量键选配色）：开始刷入后，终端界面会暂停并弹出按键提示：
  - 音量下键（-）：循环切换配色选项（素装 ➔ 一点红 ➔ 烈焰）；
  - 音量上键（+）：确认选择当前高亮的配色选项。
  - 单配色包只有一套配色，会**自动选中、不弹菜单**，也不会打扰你。
- Step 3（重启生效）：终端提示刷入完成后，点右下角「重启」按钮或手动重启手机。
- Step 4（切字体 + 打开 WebUI）：
  - 小米 / 澎湃用户：先去 设置 ➔ 系统个性化 ➔ 字体 ➔ 切为【小米兰亭Pro】；
  - KernelSU / APatch：回到【模块】列表，点「保时捷字体」卡片上的 WebUI 按钮；
  - Magisk：点卡片上的「执行」按钮，调起 KsuWebUI；
  - 在网页里点配色卡片切换配色。

七、通用排查顺序（出问题先按这个走）

1. 打开 WebUI，看「实际挂载」是否成功、数字是否接近「已替换槽位」；
2. 点「查看诊断报告」，看「实际生效（逐个核对）」的比例；
3. 若提示「本次开机没有执行自带挂载」，到「替换范围（高级）」关闭「模块自带挂载」，改为「交给管理器挂载」，重新选一次配色后重启；
4. 小米 / 澎湃用户确认已按第四节切到【小米兰亭Pro】；
5. 仍然不行：在诊断报告里点「保存到 Download」，把报告 + 机型 + 系统版本发到评论区或 GitHub Issues。
